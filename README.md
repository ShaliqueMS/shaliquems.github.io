# Shalique M.S. — Academic Personal Website

A responsive, single-page academic website initially informed by the **June 2026 CV** and photographs supplied for the farmer decision-making field project, the **Behavioural Insights for Policy (BiP) India Workshop 2026** with King's College London, and the **Reimagining Keralam** capability development programme for Kerala ministers.

## Preview on your computer

Open `index.html` in any modern browser. It works without a server. All photographs, styling and interactive gallery are included locally. Google Fonts will be used if available, but the site also has local fallback fonts.

## Publish the site

Choose any static hosting provider (GitHub Pages, Netlify, Cloudflare Pages or similar). Upload the **contents** of this folder, keeping the `assets` directory intact. No build step, database or paid hosting is required.

For GitHub Pages: Create a repository; upload `index.html`, `styles.css`, `script.js` and `assets/` to the repository root; enable Pages in Repository Settings > Pages. For Netlify: drag the unzipped folder into the Netlify deploy UI.

## Customize

- Edit sections and wording in `index.html`.
- Change colors and typography in `styles.css` near the `:root` block.
- Replace images in `assets` while keeping their filenames (or update references in `index.html`).
- Replace or update the contact email if you change institutions.

## Included files

- `index.html` — all site text and structure
- `styles.css` — visual design and mobile responsiveness
- `script.js` — navigation, photo lightbox, reveal effects
- `assets/*.webp` — optimized versions of user-provided photographs
